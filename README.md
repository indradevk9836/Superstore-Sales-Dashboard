# 📊 SuperStore Sales Dashboard – SQL + Power BI

---

# Project Summary

This project presents an interactive **Sales Analytics Dashboard** built using **PostgreSQL** and **Power BI**. The dashboard analyzes sales performance, profit, customer segments, shipping trends, and regional performance, enabling data-driven business decisions.

---

# Key Objectives

- Analyze sales, profit, and order performance.
- Monitor KPIs such as Total Sales, Orders, Profit, and Shipping Days.
- Compare sales across regions, customer segments, product categories, and payment modes.
- Identify monthly sales and profit trends.
- Build an interactive dashboard for business reporting.

---

# Key Insights

- West region recorded the highest sales.
- Consumer segment generated the largest share of revenue.
- Technology was the top-performing product category.
- Standard Class was the most preferred shipping mode.
- Sales increased significantly during the last quarter of the year.
